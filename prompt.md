Recently my city has banned "Păcănele" (slot machines), so i got the ideea to build a tongue-in-cheek website called "Păcănele" for "those that will miss them"
https://cluj24.ro/pacanelele-interzise-la-cluj-pokerul-primeste-unda-verde-iar-emil-boc-promite-ca-va-supraveghea-sala-de-la-geam-303495.html

Păcănele in very coloquial romanian term that means slot machines.
The word has its roots in the sound the slot machines make when the players hit the buttons ("pac! pac!" - a sharp clacking/clicking/banging sound the plastic buttons make as the players hit them repeatedly) on slot machines (the ones with large buttons, not pull levers).
It has a negative connotation (somewhat seedy, ironic or derogatory), as these slot machines are pure randomness and only gamblers fall prey to them. It evokes cheap gambling halls, addiction, losing money, aggressive advertising, and the social problems associated with gambling

I want the website to be cheeky, entertaining and interactive, slightly making fun of Păcănele - just a fun 2 minutes experience.

Build a hyper-realistic "Păcănele" slot machine as one self-contained three.js/webgl html page: HDR-lit room, physically based glass, metal, plastic and lights, interactive and animated slot machine, realistic sounds, DoF, fullscreen.
The users should be able to interract with the slot machine, and it should have realistic animations and sounds.

I want the text of the website to be in romanian, and for comedic effect we can use several phrases:
- Mai dă o gheară / Bagă o gheara = play one more time / play one time
- Mai bag o fisă = play one more round
- Mai dau o gheară și plec / Mai dau o gheară și mă duc / Ultima gheară! / Ultima sută = one more round and i'm leaving/i'm out
- M-a curentat, frate! / Mamă, m-a curentat / M-a ars / M-a fript / M-a spart / M-a ras / M-a curățat / M-a rupt = it burned me, took all my money
- L-am spart / Am spart banca = i broke the machine, won big
- Hai cu șeptarii! / Dă-i cu șeptarii! / Bagă șeptarii! = come one, give me sevens (77777)
- Mi-a dat linie = one line winning combination
- Mi-a dat speciala = special bonus
- pe plus / pe minus / pe zero = winning / losing / same amount as i started with
- Bagă bine / e cald / sta sa dea  = the machine is giving money (winning streak)
- E rece / e mort / e defect / e setat = the machine is not paying (losing streak)
- Las că îl întorc eu = i'll turn it around (after a loss)
- Îmi scot banii și plec = I'll play until i get my money back then leave (when on a losing streak)
- Am simțit, băi, am simțit! / Am știut eu! / L-am mirosit! / L-am simțit! = after a win - I knew it would pay!
- Băga-mi-aș picioarele! = frustrated after a loss - fucking hell!
- Mamă, ce linie! = when winning a line
- Bine mă! = when winning - Good job!
- Așa mai merge! = when winning after a losing streak, Now we're playing
- Bagă mare! = increase the stakes

The website should work both on desktop and mobile.
Feel free to download or install libs and free assets, but do not include external links that might break later (popular cdn for threejs is fine for example, but some image/texture/audio from a random website is not)
